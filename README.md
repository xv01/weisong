微讼ai是一款服务于企业和青年律师的通用AI法律工具，可以查询判例，企业信息和法律法规

#用户协议
微讼AI用户协议  
一、服务内容  
1. 本APP提供AI法律咨询、文书生成及诉讼流程辅助服务，所有内容仅供参考，不构成正式法律意见。  
2. 服务范围包括但不限于：合同审查、法律问答、案例检索等，具体功能以版本更新为准。  

二、用户权利与义务  
1. 用户权利：  
   • 享有基础功能免费使用权  
   • 对生成内容提出修正需求  
2. 用户义务：  
   • 不得上传虚假或违法信息  
   • 禁止利用服务从事商业倒卖  

三、隐私保护  
1. 收集信息类型：注册手机号、咨询记录及设备信息（仅用于服务优化）。  
2. 数据加密标准：采用AES-256加密存储，第三方审计每年1次。  

四、免责声明  
1. AI生成内容可能存在误差，用户需自行判断使用风险。  
2. 因网络故障导致的服务中断，本平台不承担连带责任。  

五、知识产权  
1. 用户上传的原创内容著作权归用户所有，但授予本平台非独占使用权。  
2. APP内所有代码、界面设计版权归运营方所有，禁止逆向工程。  

六、违约责任  
1. 用户违规操作将面临账号冻结，情节严重者移交司法机关。  
2. 平台若违反隐私条款，需按用户实际损失赔偿。  

七、协议修改与终止  
1. 修改协议需提前15天在官网公示，用户继续使用视为接受。  
2. 用户可随时注销账号，注销后数据保留30天（法律要求除外）。  

签署提示：勾选“同意”即视为接受全部条款，请仔细阅读隐私政策全文。

#隐私政策
一、数据收集类型  
1. 必要信息：用户注册时的手机号、设备型号、IP地址。  
2. 使用数据：咨询记录、文书编辑内容、功能点击路径。  
3. 设备权限：仅在用户授权后获取存储权限（用于文件下载）。  

二、使用目的  
1. 手机号用于账号安全验证；  
2. 咨询数据优化AI模型准确率；  
3. 设备信息防范刷单等作弊行为。  

三、存储与加密  
1. 境内服务器存储，采用分布式加密（AES-256+SSL传输）；  
2. 聊天记录保留180天后自动匿名化处理。  

四、用户权利  
1. 访问权：通过「账号设置-数据导出」获取个人数据副本；  
2. 删除权：注销账号后30日内完成数据彻底清除；  
3. 更正权：联系客服修改绑定手机号等关键信息。  

五、数据共享规则  
1. 仅向合规第三方（如短信服务商）共享必要数据，且签署保密协议；  
2. 司法机关依法调取时，需出示正式法律文书。  

六、安全措施  
1. 每年2次渗透测试，漏洞修复响应时间<24小时；  
2. 员工访问数据需动态令牌+审批记录双认证。  

七、未成年人保护  
1. 未满14岁用户需监护人书面同意；  
2. 青少年模式默认关闭内容分享功能。  

八、政策更新  
1. 修改内容提前7天在官网公示；  
2. 重大变更（如数据出境）将通过短信通知。  

依据法规：  
• 《个人信息保护法》第13条  
• 《网络安全法》第41条  
• GB/T 35273-2020《信息安全技术》
